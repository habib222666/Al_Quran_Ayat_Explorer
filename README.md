# আল-কুরআন ও আয়াত অনুসন্ধান

**বাংলা পরিচিতি:** আল কুরআনের আয়াত অনুসন্ধান ও বিষয়ভিত্তিক অধ্যয়ন

## Project Overview
A Web and Android application for reading, searching, studying, and listening to the Holy Quran.

## Core Features
- Complete Quran: 114 Surahs and 6,236 Ayahs
- Verified Arabic Quran text
- Bengali translations with source attribution
- Multiple Bengali Tafsir books
- Audio recitation by multiple reciters
- Online and offline reading and audio
- Search by Surah, Ayah, Arabic, Bengali, and topic
- Topic-based Ayah Explorer
- Bookmarks, favorites, and reading progress
- Light and Dark themes
- Secure Admin Panel

## Planned Technology
- Web: HTML, CSS, JavaScript
- Android: Kotlin
- Database and Authentication: Supabase
- Web Hosting: GitHub Pages

## Data Accuracy
Arabic Quran text, translations, Tafsir, and audio must use verified sources. Copyright and distribution permissions must be checked before publishing.
